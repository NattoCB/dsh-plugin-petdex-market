# Changelog

All notable changes to this plugin are documented in this file.

## [0.1.0] - 2026-08-16

- Initial release of the petdex market plugin for DSH.
- Browse, search, and paginate the live petdex.dev catalog from the Settings UI.
- Install, enable, rename, and delete pets with a single-active companion model.
- Native macOS floating desktop pet (Swift/AppKit) that walks along the bottom of the screen, waves when a reply lands, and pops speech bubbles.
- Market sorting: curated / newest / most-liked / most-installed / alphabetical (default most-liked).
- Client-side preview sprite cache and same-origin sprite proxy (no CORS issues in the WebView).
